# GForge, LLC — Website Starter

A lightweight, mobile-friendly marketing agency starter website. Built with plain HTML, CSS and JavaScript. No dependencies or build step.

## Files
- `index.html` — homepage and content
- `styles.css` — dark ember/forge visual design and responsive layout
- `script.js` — mobile navigation and dynamic copyright year

## Preview locally
Open `index.html` in your browser.

## Before publishing
1. Replace the custom typographic GForge mark with your official logo, if desired.
2. **Add verified GForge contact information** to the contact section in `index.html` and replace the prelaunch placeholder. There is no working contact form yet.
3. Review all marketing claims and service descriptions for accuracy.
4. Optionally add actual client portfolio items with permission.
5. Keep sensitive files, credentials, and client data out of this repository (especially if it will be public).

## Upload to GitHub (no terminal)
1. Create a repository named `gforge-website` at https://github.com/new.
2. In the repository, select **Add file > Upload files**.
3. Select the **four files** listed above (the unzipped contents, not the ZIP itself).
4. Select **Commit changes**.

## Publish with GitHub Pages (static site)
For a GitHub Free account, GitHub Pages hosting requires a **public** repository. On the repository page, go to **Settings > Pages**, under **Build and deployment**, choose **Deploy from a branch**, then set `main` and `/(root)` and save. Use a public repository only after removing private information. Pages deployment can take a few minutes. For private repository Pages support, check your GitHub plan.

GitHub Pages only hosts static content. Forms requiring a server, CRM integrations, and authenticated client dashboards need additional services.
